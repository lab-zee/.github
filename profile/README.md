# Lab Z

Lab Z builds dependable software and practical systems for turning complex
information into useful decisions.

Our public repositories favor:

- clear contracts and truthful documentation;
- small, reviewable changes;
- automated, blocking quality checks;
- meaningful tests over cosmetic coverage;
- secure defaults and responsible dependency maintenance; and
- maintainable systems with explicit ownership.

Start with each repository's README for its purpose, setup, and support
information. Organization-wide contribution and security guidance is published
in this `.github` repository.
