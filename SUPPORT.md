# Support

## Getting help

Start with the affected repository's README, documentation, existing issues,
and discussions. If the question remains:

- use GitHub Discussions when the repository enables it;
- open a support issue using the repository's issue templates for reproducible
  usage problems; or
- use the support path documented by that repository for products with a
  separate service agreement.

Include the repository version or commit, environment, expected behavior,
actual behavior, minimal reproduction, and relevant sanitized logs.

Public GitHub support is best effort and does not imply a response-time or
service-level commitment. Please do not post credentials, secrets, private
data, or personal contact information.

## Security and conduct

Suspected vulnerabilities are not support requests. Follow
[SECURITY.md](SECURITY.md) and report them privately. Report conduct concerns
using the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
